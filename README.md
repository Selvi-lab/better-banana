# BANANA FIBRE – Homepage (Next.js 15 · React 19 · Tailwind 3)

    npm install
    npm run dev      # http://localhost:3000

Structure: `app/` (layout, page, globals.css) · `components/` (one file per section) · `public/images/` (product images).
Animations: scroll-reveal (`Reveal.js`), hero slider, live countdown, carousels, hover/wishlist/cart micro-interactions, scroll progress bar.
Replace the images in `public/images/` with your final high-res product photos (same filenames).
